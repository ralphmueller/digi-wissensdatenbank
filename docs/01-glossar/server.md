Ein **Server** ist im IT-Zusammenhang ein **Computer oder Programm**, das **Dienste, Daten oder Ressourcen für andere Geräte (Clients)** bereitstellt.

👉 Beispiele:

* Ein **Webserver** liefert Webseiten an Browser.
* Ein **Mailserver** sendet und empfängt E-Mails.
* Ein **Dateiserver** speichert Dokumente, auf die mehrere Nutzer zugreifen können.

Kurz gesagt:

> **Ein Server ist der Gastgeber im Netzwerk – er stellt etwas bereit, was Clients nutzen können.**
